# 02: Page Structure and Copy

Goal: one page, mobile-first (90%+ of Meta traffic is phone), loads in under 2 seconds, and the **"Book My Seat ₹499" button is visible at every scroll position** (sticky bar on mobile).

Language: Hinglish, simple, conversational. All copy below is a first draft for you to edit.

## Conversion rules we follow
- One goal only: book a seat. No navigation menu, no outbound links (except legal pages in the footer).
- Sticky bottom CTA on mobile, CTA repeated after every 1 to 2 sections.
- Seats are unlimited, so no seat counter. Urgency = real **Diwali offer deadline** + real countdown to the next batch start. No fake timers.
- Checkout opens **on the same page** (modal) so nobody is sent away.
- Exit-intent (desktop) / back-button nudge (mobile): one gentle reminder, not spam.
- Earnings disclaimer visible (required for Meta).
